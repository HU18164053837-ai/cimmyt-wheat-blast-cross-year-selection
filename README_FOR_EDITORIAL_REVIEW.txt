EDITORIAL REVIEW PACKAGE

Manuscript: Auditable cross-year selection of wheat blast resistance candidates from unbalanced historical field nurseries

Scope
This package contains the source data, numbered analysis scripts, locked parameter dictionary, generated outputs, and run records needed to reproduce the 2018–2024 analysis without access to the authors' parent project directory.

Reproduction
Run RUN_ALL.ps1. It executes scripts 04–14 in order and writes an end-to-end log and a run manifest containing script SHA256 hashes, exit status, elapsed time, and key output counts. Manual execution details are in RUN_ORDER.md.

Key documentation
- README.md: package map and interpretation boundary
- PARAMETER_DICTIONARY.md: exact operational rules and uncertainty units
- RUN_ORDER.md: automated and manual execution order
- 运行记录/: run log, manifest, and input checksums

Interpretation
The 14-member set is a reference portfolio under the locked operational rule, not a uniquely proven biological optimum. Candidate membership was determined by cross-year robustness, evidence duration, pedigree de-duplication, and prespecified tail ordering. Common-check, temporal-transfer, and background-adjusted analyses are post-selection risk characterizations and were not used to redefine the portfolio.

Source data
The raw files were obtained from the CIMMYT Research Data and Software Repository. The authoritative source records are handles 11529/10548688, 11529/10548690, 11529/10548691, 11529/10548927, and 11529/10549099. Use and redistribution remain subject to the terms attached to the original datasets.
