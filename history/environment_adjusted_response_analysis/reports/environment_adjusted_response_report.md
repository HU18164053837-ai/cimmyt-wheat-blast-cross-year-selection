# 环境校正材料效应与失效边界

## 设计

以育种圃×实际环境为聚类单位，并从环境压力估计中排除14个焦点材料。候选效应为候选在同环境非候选背景分布中的中秩百分位减0.5；负值表示优于环境中位水平。原始病害差保留为辅助字段。反应规范斜率描述环境压力升高时相对排名优势是否衰减。95%区间来自1000次环境簇bootstrap。结构性缺失不填补，不构造完整材料×年度面板。

## 结果

14个材料中14个的环境校正效应95%区间完全低于0；4个材料的压力敏感性区间跨越0，可归为在现有压力范围内未检测到系统性优势衰减。材料层面的失效频率和经验压力边界见表07。

## 解释限制

环境压力与育种圃材料构成共同变化，反应规范是描述性关联而非因果耐压参数。候选进入环境并非随机，bootstrap只传播已观测环境间变异，不能覆盖未观测目标环境。零膨胀和环境基线压缩会降低弱环境中的分辨率。
