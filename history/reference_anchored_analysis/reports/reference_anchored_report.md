# 共同对照锚定的跨环境抗性优势分析

## 方法

在每个真实育种圃×环境内部，以LOCAL CHECK/304660中位病害为基准，定义ΔDI=候选病害−LOCAL CHECK病害；负值表示候选更低。每个候选的区间通过对共享环境簇进行2,000次bootstrap获得，而不是把同一环境内记录当作独立重复。

## 主要结果

14个候选中，14个满足stable_superior：7630418、8048389、6341870、6176368、7398245、7694609、8048669、7627645、7629600、7462304、7624738、7626498、7310617、7400724；0个为conditional_advantage：。所有候选的LOCAL CHECK共享环境覆盖率均为100%，中位ΔDI范围为-76.69至-47.55个百分点；逐年剔除后所有候选的中位优势方向均保持为负。

这一高度一致性说明LOCAL CHECK是有效的感病锚点，可验证候选抗性信号，但由于对照与候选差距过大，它对14个候选内部排序的分辨能力有限。SONALIKA仅与5个候选、CHIRYA.3仅与7个候选共享环境，而且均只覆盖1年，因此只能作为局部敏感性结果，不能称为跨年度独立确认。

地点×播期分析标记了0个候选—环境层面的优势丢失记录。该标记可能来自真实条件反应，也可能来自共享环境较少，因此必须同时查看n_strata和原始ΔDI。

## 解释边界

LOCAL CHECK是跨年度尺度锚点，不是随机抽取的统一品种；其身份和管理可能随育种圃语境变化。锚定差值减少了环境压力和材料构成变化的影响，但不能替代平衡随机试验。SONALIKA和CHIRYA.3只在共享环境中作为辅助敏感性参照。
