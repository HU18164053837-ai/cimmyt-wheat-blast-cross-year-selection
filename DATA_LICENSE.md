# Data provenance and licensing notice

The wheat blast nursery data used by this repository were obtained from the CIMMYT Research Data and Software Repository:

| Handle | Dataset scope |
|---|---|
| 11529/10548688 | 8th–12th HLBSN wheat blast data |
| 11529/10548690 | 50th–52nd IBWSN wheat blast data |
| 11529/10548691 | 35th–37th SAWSN wheat blast data |
| 11529/10548927 | Seven CIMMYT wheat nurseries, 2022 cropping cycle |
| 11529/10549099 | Six CIMMYT wheat nurseries, 2023 cropping cycle |

The files were accessed on 12 August 2026. The repository preserves a source snapshot and download manifest for reproducibility. No ownership of the CIMMYT data is claimed, and the MIT license in this repository does not apply to those files or override the terms displayed by the source repository.

Before reusing or redistributing source or derived data, users must review and comply with the terms attached to the corresponding CIMMYT dataset. When in doubt, download the data directly from the persistent handles and cite the original dataset creators.

Candidate GIDs and reported pedigrees support identity tracing, but current germplasm availability is not guaranteed. Requests for physical germplasm should be directed to CIMMYT or the relevant originating breeding program.
